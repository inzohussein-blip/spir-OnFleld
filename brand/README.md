# شعار احجزلي بالملعب — EHJEZLY

ملفات رسم متجه (Vector) تنفتح بـ CorelDRAW و Illustrator و Inkscape. الكتابة محوّلة لأشكال، فما تحتاج الخط منصّب.

| الملف | الاستعمال |
|---|---|
| `ehjezly-logo-full` | الشعار الكامل على الخلفية الزرقاء (مربع) |
| `ehjezly-logo-transparent` | بدون خلفية — للخلفيات الغامقة (الكتابة والاعب أبيض) |
| `ehjezly-logo-on-white` | بدون خلفية — للورق الأبيض (اللاعب و«بالملعب» كحلي) |
| `ehjezly-mark` | العلامة بس: اللاعب والقوس والدبوس |

كل ملف بأربع صيغ: **PDF و EPS و SVG** (رسم متجه) و **PNG** (صورة).
بكورل: File ← Open ← اختار ملف PDF أو EPS أو SVG.

الألوان: أزرق `#1A23C9`، أصفر `#FFD60A`، كحلي `#0B1033`، أبيض `#FFFFFF`. الخط: Readex Pro Bold.
