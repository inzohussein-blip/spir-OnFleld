# بالملعب ⚽

منصة عربية لحجز ساحات كرة القدم (خماسي / سباعي / أي عدد)، وتنظيم المباريات، وتجهيز الفرق، وتقييم اللاعبين.

- 📱 **تطبيق اللاعبين** (`apps/mobile`): أندرويد + ويب آب (PWA) للآيفون — كود واحد بـ Expo.
- 🗄️ **الخلفية** (`supabase/`): PostgreSQL + مصادقة OTP + صلاحيات RLS.
- 📄 [خطة المشروع الكاملة](docs/PLAN.md)

## تنزيل تطبيق الأندرويد (APK)

يُبنى تلقائياً على GitHub مع كل تحديث:

1. افتح تبويب **Actions** ← **Android APK** ← آخر تشغيل ناجح.
2. نزّل **balmalaab-android** من أسفل الصفحة (ملف zip فيه الـ APK).
3. انقله للهاتف وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

لإصدار رسمي في تبويب Releases: أنشئ وسماً مثل `v0.1.0` وادفعه.

## نسخة الآيفون (ويب آب)

1. في إعدادات المستودع: **Settings ← Pages ← Source: GitHub Actions** (مرة واحدة).
2. بعد الدمج في فرع `main` يُنشر التطبيق على `https://<اسم-المستخدم>.github.io/spir-OnFleld/`.
3. على الآيفون: افتح الرابط في Safari ← زر المشاركة ← **إضافة إلى الشاشة الرئيسية**.

## الوضع التجريبي وربط Supabase

بدون إعداد، يعمل التطبيق **بوضع تجريبي** ببيانات وهمية على الجهاز (رمز الدخول: `1234`).

للربط بقاعدة بيانات حقيقية:

1. أنشئ مشروعاً على [supabase.com](https://supabase.com) ونفّذ ملفات `supabase/migrations` بالترتيب.
2. فعّل الدخول برقم الهاتف (Authentication ← Providers ← Phone) واربطه بمزوّد SMS.
3. أضف في **Settings ← Secrets and variables ← Actions**:
   - `EXPO_PUBLIC_SUPABASE_URL`
   - `EXPO_PUBLIC_SUPABASE_ANON_KEY`

## لوحة التحكم (للإدارة)

إنشاء المباريات صار من لوحة التحكم فقط، وهي تنفتح بالمتصفح على `/admin`. مثلاً: `https://<اسم-المستخدم>.github.io/spir-OnFleld/admin`.

- **مباراة جديدة:** تختار الملعب، واليوم، والساعة (الساعات المحجوزة تبين معطّلة)، والمدة، والعدد، والمستوى، وموعد فتح التسجيل.
- **اقتراحات اللاعبين:** اللاعبين يقترحون مباريات من «حسابي ← اقترح مباراة». تحوّل الاقتراح لمباراة بضغطة، وصاحبه يوصله إشعار.
- **الملاعب والصور:** ترفع صورة لكل ملعب.

لتعيين مدير بقاعدة البيانات الحقيقية:
```sql
update profiles set role = 'admin' where id = '<معرّف المستخدم>';
```
بالوضع التجريبي اللوحة مفتوحة للتجربة.

## الإشعارات

**الإشعارات المحلية تشتغل فوراً بدون أي إعداد:**
- تذكير قبل المباراة بساعتين، لكل مباراة ينضم لها اللاعب.
- «ذكّرني عند فتح التسجيل» للمباريات اللي تسجيلها ما فتح بعد.

**إشعارات الخادم** (مثل «دخلت المباراة من قائمة الانتظار» و«اقتراحك صار مباراة») تنحفظ بجدول `notifications` وتطلع داخل التطبيق دائماً. حتى توصل للهاتف وهو مسكّر، تحتاج:
1. مشروع على [expo.dev](https://expo.dev). ضيف `projectId` بملف `app.json` تحت `extra.eas.projectId`.
2. مشروع Firebase. ارفع مفتاح FCM لمشروع Expo، وضيف `google-services.json` للتطبيق.
3. انشر الدالة `supabase/functions/send-push`، واربطها بـ Database Webhook على جدول `notifications` (الخطوات مكتوبة بأعلى ملف الدالة).

## روابط الدعوة

زر المشاركة يرسل رابط ويب يفتح المباراة عند أي شخص، حتى لو ما عنده التطبيق. إذا ما كان مسجّل دخول، يرجع لنفس المباراة بعد الدخول. الرابط الأساسي موجود بملف `apps/mobile/src/config.ts` (`WEB_URL`).

## التطوير محلياً

يتطلب Node.js 22.18 أو أحدث (يُبنى على GitHub بـ Node 26 LTS).

```bash
cd apps/mobile
npm install
npm run web        # في المتصفح
npm run android    # على جهاز/محاكي أندرويد
npm run typecheck && npm run lint && npm test   # TypeScript 7 + ESLint 10 + الاختبارات
```
