# ربط «احجزلي بالملعب» بقاعدة بيانات Supabase

هذا الدليل ينقل التطبيق من **الوضع التجريبي** (بيانات وهمية على الهاتف) إلى **قاعدة بيانات حقيقية**،
فيصير كل اللاعبين يشوفون نفس المباريات، ويسجّلون دخول بحساباتهم، وتنحفظ بياناتهم.

**الوقت المتوقع:** حوالي 30 دقيقة.
**الكلفة:** مجاني. الاستثناء الوحيد رسائل رمز الدخول (SMS)، وتفاصيلها بالخطوة 4.

---

## الخطوة 1: اختار الحساب وسوّ المشروع

1. ادخل [supabase.com/dashboard](https://supabase.com/dashboard) بالحساب اللي تريد تربط عليه.
2. **New project**:
   - **Name:** `balmalaab` (أو أي اسم).
   - **Database Password:** اختار كلمة سر قوية **واحفظها**. ما تحتاجها للتطبيق، بس تحتاجها إذا ردت تتصل بقاعدة البيانات مباشرة.
   - **Region:** `Central EU (Frankfurt)`، أقرب منطقة للعراق.
   - **Plan:** Free.
3. انتظر دقيقة لحد ما يجهز المشروع.

> ملاحظة: الحساب المجاني يسمح **بمشروعين شغالين** بس. إذا الحد ممتلئ، أوقف (Pause) مشروع ما تستعمله.
>
> بحساب **spir.hub** أكو هسه مشروع فارغ اسمه `balmalaab` بفرانكفورت، سويته أنا. إذا اخترت هذا الحساب استعمله مباشرة، وإذا اخترت حساب ثاني نحذفه.

---

## الخطوة 2: سوّ الجداول (مرة وحدة)

1. من المشروع: **SQL Editor ← New query**.
2. افتح الملف [`supabase/setup.sql`](../supabase/setup.sql)، وانسخ **كل** محتواه والصقه، واضغط **Run**.
   - الملف يسوي كل شي: الجداول، والصلاحيات، والدوال، ومكان الصور، والإشعارات، والمهام الدورية.
   - إذا طلعت رسالة عن `pg_cron`: روح **Database ← Extensions**، فعّل **pg_cron**، وأعد تشغيل الملف. إعادة التشغيل آمنة.
3. تأكد: **Table Editor** لازم يبين بيه جداول مثل `profiles` و `venues` و `matches`.

---

## الخطوة 3: انسخ مفاتيح الربط

من **Project Settings ← API Keys** (أو **Data API**) انسخ:

| القيمة | وين تلكاها | شكلها |
|---|---|---|
| **Project URL** | Data API ← Project URL | `https://xxxxxxxx.supabase.co` |
| **Publishable / anon key** | API Keys | يبدي بـ `sb_publishable_` أو `eyJ` |

> ⚠️ **لا تنسخ** `service_role` أو `secret`. هذا مفتاح سري ما ينحط بالتطبيق أبداً.

---

## الخطوة 4: طريقة تسجيل الدخول

التطبيق مبرمج هسه على **رقم الهاتف + رمز SMS**، وهاي الخيارات:

| الطريقة | الكلفة | شنو نحتاج |
|---|---|---|
| **رقم الهاتف (SMS)**، الحالية | الرسالة للعراق تقريباً 0.05–0.25 دولار | حساب عند مزوّد رسائل (Twilio أو Vonage أو MessageBird) |
| **أرقام تجريبية** برمز ثابت | مجاني | للتجربة ويا فريقك قبل الإطلاق بس |
| **حساب Google** | مجاني | إعداد بـ Google Cloud، وتعديل بالتطبيق |
| **رمز على الإيميل** | مجاني بحدود (البريد المدمج بطيء ومحدود) | تعديل بالتطبيق |

**الإعداد لرقم الهاتف** (Authentication ← Sign In / Providers ← **Phone**):
1. فعّل **Enable Phone provider**.
2. اختار المزوّد (مثلاً **Twilio**) وحط بياناته: Account SID و Auth Token و Message Service SID.
3. **للتجربة بدون رسائل:** بنفس الصفحة، بـ **Test Phone Numbers and OTPs** ضيف أرقام برمز ثابت، مثلاً `9647700000000=123456`.
   - Supabase ممكن يطلب تعبئة بيانات المزوّد حتى للأرقام التجريبية.
   - الأرقام التجريبية للفريق بس، مو للاعبين.

> إذا تريد **Google** أو **الإيميل** بدل الهاتف، كلّي وأعدّل شاشة الدخول بالتطبيق.

---

## الخطوة 5: حط المفاتيح بـ GitHub

بالمستودع: **Settings ← Secrets and variables ← Actions ← New repository secret**، وضيف اثنين:

| الاسم (Name) | القيمة (Secret) |
|---|---|
| `EXPO_PUBLIC_SUPABASE_URL` | الـ Project URL من الخطوة 3 |
| `EXPO_PUBLIC_SUPABASE_ANON_KEY` | الـ Publishable / anon key من الخطوة 3 |

بعدها أي نسخة جديدة تنبني تشتغل على قاعدة البيانات الحقيقية تلقائياً، للأندرويد وللويب.
إذا المفاتيح مو موجودة، التطبيق يرجع للوضع التجريبي، فما يتعطل.

---

## الخطوة 6: ابنِ نسخة جديدة وسوّ حسابك مدير

1. ابنِ نسخة جديدة (أو كلّي وأطلقها).
2. نصّبها وسجّل دخول برقمك (أو برقم تجريبي).
3. من «حسابي» انسخ **رقمك (ID)** اللي يطلع تحت بطاقتك.
4. افتح [`supabase/seed_template.sql`](../supabase/seed_template.sql) بـ **SQL Editor**:
   - بدّل القيم بين `< >`: رقمك، واسم الملعب، والمنطقة، والموقع، والساحات وأسعارها.
   - اضغط **Run**. حسابك يصير **مدير**، وينضاف أول ملعب.
5. من **لوحة التحكم** بالمتصفح: ضيف صور الملاعب، وعيّن الموظفين، ونزّل أول مباراة. 🎉

---

## اختياري: إشعارات تنوصل والتطبيق مسكّر

الإشعارات تطلع داخل التطبيق بدون أي إعداد إضافي.
حتى توصل للهاتف وهو مسكّر، نحتاج **Firebase**، والخطوات مكتوبة بـ [README](../README.md) تحت «الإشعارات».
نسويها بعد ما يشتغل الربط الأساسي.

---

## ملاحظات مهمة

- **المشروع المجاني يتوقف** إذا ما انستخدم **7 أيام**. لما التطبيق يشتغل وأكو مستخدمين ما يتوقف، ولو توقف يرجع بضغطة **Restore**.
- **حدود المجاني:**
  - قاعدة بيانات 500 ميغا.
  - صور 1 غيغا.
  - 50 ألف مستخدم شهرياً.
  - هذا يكفي لآلاف اللاعبين. وإذا كبرت، الخطة المدفوعة 25 دولار شهرياً بدون أي تغيير بالتطبيق.
- **النسخ الاحتياطي:** المجاني ما بيه نسخ تلقائية يومية. أنصح تاخذ نسخة يدوية كل فترة من **Database ← Backups** أو بالتصدير.
- **تحديث الجداول مستقبلاً:** أي تعديل جديد ينضاف كملف بـ `supabase/migrations`. شغّل **الملف الجديد بس** بـ SQL Editor، مو `setup.sql` كامل.
